IT request — Capacity Tracker on the Production site
====================================================

Site:
  https://fuseintegration.sharepoint.us/sites/Production

What we need
------------
A custom web app on a modern SharePoint page, talking to four
SharePoint lists on the same site, so the shop floor shares one
capacity board (work centers, employees, PTO, work orders).

HTML/ASPX in Documents does not run on this tenant (files
download). We are not asking to host this on GitHub Pages.


Please do ONE of the following


Option A — preferred (modern SharePoint)
----------------------------------------
1. Confirm this site can use the tenant App Catalog.
2. We will provide a SharePoint Framework (.sppkg) package.
3. Upload it to the App Catalog and make it available to
   the Production site.
4. We add the web part to a page on Production.

The app only calls this site's REST API as the signed-in user.
No extra Azure AD app, no data leaving the tenant.


Option B — allow custom script on this site only
------------------------------------------------
Allow custom script / custom pages on Production so an
.aspx page in Site Assets can run.

Then we will place the app in Site Assets (not Documents)
and point a page at it. Data still stays in SharePoint lists.


Also needed
-----------
Four lists on Production (we can create them if we have
Manage Lists, or you can run sharepoint/New-CapacityLists.ps1):

  CT Work Centers
  CT People
  CT Work Orders
  CT Time Off

Users who plan capacity need Contribute on those lists.
