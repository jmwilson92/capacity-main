Live team board — same data for everyone
=======================================

Keep using the downloaded HTML file. Do not create SharePoint lists.

Everyone who opens the SAME team HTML file shares one live board.
When someone adds a work order, it shows up on other computers
in a few seconds.


ONE PERSON SETS IT UP (5 minutes)
---------------------------------
1. Download CapacityTracker.html from the repo and open it
   (double-click the file, the way that already worked).

   https://github.com/jmwilson92/capacity/raw/main/CapacityTracker.html

2. Go to https://jsonbin.io and create a free account.

3. Click your name → API Keys → copy the Master Key.

4. In Capacity Tracker: Settings → paste the Master Key
   → Start shared board.

5. Click Download team HTML.
   That file has the board baked in.

6. Upload that CapacityTracker.html to SharePoint Documents
   (replace the old one).


EVERYONE ELSE
-------------
Open / download that file from SharePoint and open it.
They are already on the same board. No extra setup.


NOTES
-----
The board lives on JSONBin (not in Documents).
The SharePoint file is just the program + the board key.

If IT blocks jsonbin.io, the header will show an error.
You would need that site allowed outbound.
