Why the HTML file is not a live page on SharePoint
==================================================

SharePoint on your tenant treats .html as a DOCUMENT, not a website.

When you click the file it downloads. That is intentional security
on sharepoint.us. The file never “runs” in the browser the way a
normal webpage does, so Embed goes blank and the address bar cannot
host the app.

That cannot be fixed inside the HTML. Only IT can change it
(custom script / an approved app). You said no IT.

What we can do instead
----------------------
Keep using the HTML as the program (Start-CapacityTracker.bat).

Put capacity-data.json in the SAME SharePoint folder and sync that
folder with OneDrive. The JSON file is the database. SharePoint
stores it. OneDrive copies it to every PC. The HTML reads and
writes that file.

Data stays in your tenant. No JSONBin. No lists. No IT ticket.
