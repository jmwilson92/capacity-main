# Capacity Tracker / Production Suite

Shop-floor capacity, WIP, work orders, work instructions, downtime, skills, and analytics.

## Quick start

Open `index.html` or:

```bash
npm start
```

Then visit http://localhost:8080

## Apps

- `CapacityTracker.html` — work centers, people, planning, work orders
- `WorkOrders.html` — My work, check-in, travelers
- `WipBoard.html` — live board + assign tech/QA
- `WorkInstructions.html` — generic cable + product WIs
- `Analytics.html` / `DowntimeLogger.html` / `SkillsMatrix.html` / `Settings.html`

Data lives in browser `localStorage` key `capacity-tracker.v1`.
