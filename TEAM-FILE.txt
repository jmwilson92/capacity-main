Shared database next to the app (no IT)
=======================================

1. Upload this whole unzipped folder to SharePoint Documents.
2. In that folder click Sync or "Add shortcut to OneDrive".
3. On your PC, open the synced folder.
4. Double-click Start-CapacityTracker.bat (leave the window open).
5. Settings → Create team file
   Save it IN THAT SAME FOLDER as capacity-data.json
6. Other people: sync the same folder, run the .bat,
   Settings → Open existing team file → pick capacity-data.json

The HTML is the screen. capacity-data.json is the database.
OneDrive/SharePoint copies that file to everyone.
When someone adds a work order, others see it after OneDrive syncs
(usually a few seconds).
